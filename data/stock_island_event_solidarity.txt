# Village Solidarity: the tag of every result of the games' OWN island events (the owner, 2026-11-20, v1.35.97).
#
# ONE SOURCE.  "VVFP Island Events.dll" reads nothing from here at run time: scripts/build_stock_solidarity_table.py
# turns this file into native/vvfp_island_events/stock_solidarity_table.inc (tests/test_stock_event_solidarity.py
# fails when the two differ).  To change a tag: edit the TAG column, run that script, rebuild the DLL
# (scripts/build_vvfp_island_events.ps1) and re-pin it (scripts/build_island_events_features.py and
# scripts/build_village_solidarity_feature.py --no-build).
#
# When the game shows one of these results, Village Solidarity moves by its tag: RAISE +5, LOWER -5, NEUTRAL no
# change (a "no change" line in the Village Solidarity log), exactly once.  Only with the Village Solidarity row
# ticked.  Score only: no stock event, result or chance changes.
#
# Columns (" | " between them):
#   GAME    VV1 .. VV5
#   TITLE   the event's title exactly as the game shows it in English
#   ANSWER  the button picked, as its English label reads (a final "." dropped); "-" for an event with no choice
#           Any language works: the companion turns the title and the label shown back into the game's own
#           English through the game's string table (the English the exe holds, before any translation), so
#           these are always the English words.  Only the game's own events count: a Custom Island Event (or any
#           other event of the Story / Cheat Upgrades engine) that uses one of these titles is never tagged here.
#   WHEN    "-" always; else what tells this result from the others behind the same title and answer, read from
#           the village just before and just after the game applies it:
#             food+ food-   the stored food went up / down        tech+ tech-  the tech points went up / down
#             lost          a villager died or was taken away     joined       a villager joined (a believer in VV5)
#             sick          a villager fell sick                  sick2        two or more villagers fell sick
#             hurt          a villager lost health                healed       a villager gained health or was cured
#             weather       the weather changed
#           Rows with the same GAME, TITLE and ANSWER are tried top to bottom; the first whose WHEN holds is the
#           result shown.  Without a "-" row last, a result none of them matches moves nothing.
#   TAG     RAISE, LOWER or NEUTRAL
#   RESULT  what the result is (words only)
#
# Left out by the owner's word: the Gong of Wonder (The Lost Children), which is no island event.
# Counted by the owner's word: the events "Restore Missing Island Events" brings back (marked "restored").
