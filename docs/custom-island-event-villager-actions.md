# Custom Island Event: every villager action

Generated by `scripts/build_cie_actions_doc.py` from `tests/cie_behaviour_catalog.json`; do not edit by hand.

The owner (2026-10-21): "add all villager actions/behaviors to the Villager Changes section in the Custom Island Event. Especially 'Celebrating'", then "Behaviors from: Island events, Puzzles, Golden Child behaviors, Heathen behaviors, Chief behaviors -- literally anything villagers can do, on everyone regardless!!!"

Each game's list holds every action the game's own code can start for a villager -- its jobs and idle actions, the island events', the puzzles', the Golden Child's, the Tribal Chief's and the Heathens' -- offered for any villager.  Each label is the text the Details screen shows once the villager does it (an action that can show more than one text names them; a note in brackets says where an action comes from or what it gives).  The villager is stopped first and the game's own starter runs (A New Home and The Lost Children: the starter routine with the villager's index; the later games: the do-action routine with the action id and an argument block of zeros).

An action that may harm the game or the save ends **(Unsafe)**: choosing it shows the reason and advises backing up the save first (Back Up Saves), OK / Cancel.  One that would need a missing object is refused when the event happens (the villager is not changed) instead of crashing the game.

Evidence: `tests/test_cie_behaviour_labels.py` re-derives every label's text from the stock executables; `tests/test_cie_behaviours_emulated.py` starts every action in an emulated stock executable for an adult, a child and (New Believers) a Heathen and checks the Details text and action code.  Not run in the game.
