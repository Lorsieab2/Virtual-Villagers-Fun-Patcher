VIRTUAL VILLAGERS - ISLAND EVENT CONDITIONS (DETAILED)
=======================================================

What every island event in the five games needs before it can happen, what it then does and to whom,
read from the five stock executables (research/stock-executables). Every clause cites the code that
makes it.

Evidence level: static analysis of the exact stock executables (disassembly). NOT yet confirmed in a
running game. Where a field's meaning could not be established it is named as an internal field with
its address and "meaning not determined", never guessed.

How to read an entry
  [slot N] the value Pick Island Event uses (scripts/story_island_events.py). In A New Home and The
           Lost Children it is family x 64 + index (A New Home: 0 Island, 1 Encounter, 2 Crate; The
           Lost Children: 0 Single-result, 1 Two-choice, 2 Sack); in the other three games it is the
           index in the game's own event table.
  Needs:   every condition, all of which must hold at the moment the game picks the event. Clauses
           that pick the villager the event is about ("the subject") are included -- if no villager
           fits, the event cannot be picked.
  Then:    what the event does and to whom.
  Repeat:  shown only when special. No island event in any of the five games is limited to once per
           village and none has a cooldown of its own; only the shared timer between island events
           (in each game's rules) spaces them out.
  Code:    the condition function and the addresses behind each clause.

Units and words
  * Ages: the games store 20 age units per displayed year (280 = 14 years, 360 = 18, 1000 = 50).
  * "Living" = the record is in use and health is above 0 (each game's exact fields are in its rules).
  * "Pregnant or nursing" is one state in all five games (the record's pregnancy field is non-zero).
  * Technology "level": the value the game's own technology getter returns (0 = nothing researched).
  * Population caps: "90" is the stock cap; the patcher's population modes (Collection Progression,
    Immediate Fixed) change that base number and everything else stays as described.
  * Pick Island Event (the patcher's Origins upgrade) uses exactly these conditions: an event whose
    Needs do not hold cannot be delivered.

====================================================================================================
A NEW HOME  (VV1)
====================================================================================================

Rules for all island events in this game:
  * Island family (body 0x427CA0): the case is rand(15) at 0x4284DB, re-rolled until its check
    passes. Its strength (magnitude) is the population (with carried babies) divided by 3, kept
    between 1 and 10 (0x4239AD).
  * Encounter family (body 0x4189E0): the variant is rand(16) at 0x418932, re-rolled until its class
    check passes.
  * Crate family (0x42D0E0 -> 0x42B000): one rand(9) at 0x42B03E, no re-roll and no conditions; a
    strength roll rand(100) at 0x42B00C gives 1 (below 33), 2 (33-66) or 3 (67+).
  * Timing: the next island event time is world+0xA300 in game-clock seconds (clock 0x402F70). A new
    village sets it to 15 minutes after creation (0x41C4A9: +0x384). When a village is loaded and an
    internal value world+0xA318 is 999 or more (meaning not determined), the time since world+0xA304
    is added (0x42E90A-0x42E930).
  * When the time has come (0x4237BD), an event is attempted only if the population (0x41CF90) is
    above 0 and a living villager aged 14 or over exists (0x43BCD0(1)); that randomly drawn
    villager's age (+0x348) must also equal its field +0x34C (named 'Nursing' in the owner's Cheat
    Engine table; why the check uses it was not determined). If either fails, nothing is rescheduled
    and the trigger tries again on its next update.
  * Family weights (0x423818, 0x42383A): if the village's Island Events Seen counter (world+0x9E40,
    saved) is 0, the event is always an Encounter. Otherwise a first rand(100) below 20 gives an
    Encounter (20%); else a second rand(100) below 50 gives an Island event (40%), and 50 or more
    gives a Crate (40%). (The extra branch guarded by 0x41D110 never runs: it always returns 0.)
  * Delay to the next event: after the village's first event, 30 minutes (+0x708); after any other
    event, 12 to 23 hours ((rand(12)+12) x 3600 s). The counter world+0x9E40 goes up by 1 each time.
  * Retries inside a family: the Island chooser (0x4284D6) and the Encounter chooser (0x418930) re-
    roll without limit until a case passes its check (both always have unconditional cases, so they
    always end). The Crate chooser rolls once.
  * No event is limited to once per village and there is no per-event cooldown.
  * Ages: 20 age units = 1 displayed year; children are under 14 (280 units). Records: present
    +0x28, health +0x344, age +0x348.
  * Room check (used by the events that add villagers): room for new villagers, by the game's own
    room check 0x43A1A0: the population (living villagers plus babies being carried, as 0x41CF90
    counts them) must be below 90 in the stock game (the patcher's population modes change this
    cap); 15-24 people need the first small hut built (world+0x9FE8), 25-49 need the second
    (+0x9FF0), 50 or more need the third (+0x9FF8); under 15 needs none.

  Note: Technology fields: the Technologies screen draws its six rows from world+0xA2E4, +0xA2D4,
        +0xA2DC, +0xA2CC, +0xA2C4, +0xA2BC (0x433BE6-0x433CA3) and its six labels in the order
        Farming, Medicine, Fertility, Construction, Science, Spirituality (strings 0x8D-0x92,
        0x435849-0x4358C6). Pairing them in order gives +0xA2BC = Spirituality, +0xA2D4 = Medicine,
        +0xA2E4 = Farming; +0xA2D4 is corroborated by its lifespan use at 0x42EDFC. The earlier
        description of The Trapped Whale and The Visitor as 'happened fewer than three times' is
        wrong: both compare a technology level with 3.

====================================================================================================
THE LOST CHILDREN  (VV2)
====================================================================================================

Rules for all island events in this game:
  * Single-result family (body 0x433600): the case is rand(28) at 0x434607, up to 10 draws (see
    retries). Its strength (magnitude) is the population divided by 3, kept between 1 and 10
    (0x42F09E).
  * Two-choice family (case bodies, table 0x420454): rand(22) at 0x41F59D; 21 is always rejected.
  * Sack family (0x437AC0): one rand(8) at 0x437B0E, no re-roll and no conditions; a strength roll
    rand(100) at 0x437ADC gives 1 (below 33), 2 (33-66) or 3 (67+).
  * Timing: the next island event time is world+0x2EAE0 in game-clock seconds (clock 0x403200). A
    new village sets it to 15 minutes after creation (0x42529B: +0x384). When a village is loaded
    and an internal value world+0x2EB08 is 999 or more (meaning not determined), the time since
    world+0x2EAE4 is added (0x43B690-0x43B6C8). A stock routine at 0x44EC85 (which spawns 20
    objects) also sets the next event to 60 seconds later (0x44ECE1).
  * When the time has come (0x42EECD), an event is attempted only if the population (0x425860) is
    above 0 and a living villager aged 14 or over exists (0x44BAE0(1)); that randomly drawn
    villager's age (+0x530) must also equal its field +0x534 (named 'Nursing Timer' in the owner's
    Cheat Engine table; why the check uses it was not determined). If either fails, nothing is
    rescheduled and the trigger tries again on its next update.
  * Family weights (0x42EF28, 0x42EF4A): if the village's Island Events Seen counter (world+0x2E51C,
    saved) is 0, the event is always from the two-choice family. Otherwise rand(100) below 20 gives
    a two-choice event (20%); else a second rand(100) below 50 gives a single-result event (40%) and
    50 or more a Sack/Vial (40%). (The branch guarded by 0x426110 never runs: it always returns 0.)
  * Delay to the next event: after the village's first event, 30 minutes (+0x708); after any other,
    10 to 19 hours ((rand(10)+10) x 3600 s). The counter world+0x2E51C goes up by 1 each time.
  * Retries inside a family: the single-result chooser draws up to 10 times and, if none passes,
    runs Blessings Day Celebration (first version, case 10). The two-choice chooser draws up to 10
    times and, if none passes, runs The Voices In The Brush (case 5). The Sack chooser rolls once.
  * No event is limited to once per village and there is no per-event cooldown.
  * Ages: 20 age units = 1 displayed year; children are under 14 (280 units). Records: present
    +0x30, health +0x52C, age +0x530, gender +0x538 (1 male, 2 female).
  * Room check (used by the events that add villagers): room for new villagers, by the game's own
    room check 0x44B310: the population (living villagers that are not totems -- record +0x558 clear
    -- plus babies being carried, 0x425860) must be below the cap -- 90 in the stock game (the
    patcher's population modes change this number) plus 5 for each of the four children's
    collections completed (12 pieces each, 0x426120; all four give 25) -- and 15-24 people need 1
    hut built (world+0x2E818), 25-49 need 2, 50 or more need all 3 (+0x2E820, +0x2E828); under 15
    needs none.

  Note: Technology fields: the Technologies screen draws its rows from world+0x2EA9C, +0x2EA8C,
        +0x2EA94, +0x2EA84, +0x2EA7C, +0x2EA74 (0x4418F6-0x4419B3) and its labels in the order
        Farming, Medicine, Exploration, Engineering, Science, Culture (strings 0xC9-0xCE). Pairing
        them in order gives +0x2EA74 = Culture and +0x2EA94 = Exploration; +0x2EA84 = Engineering is
        corroborated by the hut-building gate (docs/builders-fix-huts.md). The earlier descriptions
        'the gold-coin fashion not to have caught on already' and 'the spyglass not to have been
        kept already' were wrong: both compare a technology level with 2.
  Note: 'The village's later technologies' in the earlier description of The Epidemic, Rats!, The
        Foul Passing and Where Are The Infants? is wrong: the check 0x4261D0 requires all 16 puzzles
        solved.

====================================================================================================
THE SECRET CITY  (VV3)
====================================================================================================

Rules for all island events in this game:
  * Timing: the next island event time is kept at manager+0x12EF4 in game-clock seconds (clock
    0x403330). A new village sets it to 15 minutes after creation (0x4280B2: +0x384). When the time
    has come, the event is attempted only if the population (living villagers plus babies being
    carried, 0x45E8F0) is above 0.
  * Before every attempt the scheduler draws a random villager aged 14 or over (0x45C9D0(1)); there
    must be one, and an internal check must pass: that villager's age (+0xDC4) must equal its
    internal field +0xE74 (meaning not determined; the game writes both together, e.g.
    0x417440/0x417449). If the check fails nothing is rescheduled and the scheduler tries again on
    its next update (0x468750-0x468792).
  * Delay to the next event: the first island event after the game is started (in-memory counter
    0x5824C4, not saved) schedules the next one 30 minutes later (+0x708); every later one schedules
    the next 8 to 15 hours later ((rand(8)+8) x 3600 s). The extra rand(100) rolls at 0x468798 and
    0x4687B8 do not change this (0x402200 always returns 0).
  * When a village is loaded and an internal value manager+0x12F20 is 999 or more (meaning not
    determined), the time the game was closed is added to the next-event time (0x428C60-0x428C8B).
  * Choice (selector 0x419B30): every one of the 57 slots whose own condition holds is collected,
    and one is picked uniformly at random. No retries: if none qualifies, nothing happens and the
    next event is still rescheduled. Calling the conditions also picks the subject villagers.
  * Rescue rule (0x419B85-0x419BD9), applied after the pick: if (there are more men than women and
    at most 2 women), or (men do not outnumber women and there are at most 2 men) -- counting living
    villagers of all ages (0x45EA80) -- or the population including carried babies is below 3, then
    with a 15% chance the choice is replaced WITHOUT checking that event's own condition: a first
    roll below 30 gives The Crystal of Reflections (slot 18), 30-59 gives The Canoe from the Other
    Side (slot 7), 60 or more gives Another One of Those Barrels (slot 57).
  * No event in this game is limited to once per village: the selector's per-slot 'shown' bytes at
    0x4B3C3C+slot (written at 0x419C22) are never read.
  * Ages: 20 age units = 1 displayed year. 'Child' = under 14 (280), 'adult' in the picker = 18-49
    (360-999), 'elder' = 50+ (1000). The picker 0x45D460 counts only villagers alive (health +0xE78
    > 0) and present (+0xF10). Its 'adult' class also requires +0xE8C (pregnant/nursing) to be 0.
    Its optional exclusion skips the Tribal Chief (+0xE80).
  * Room check (used by the events that add villagers): room for a new villager, by the game's own
    room check: the population (living villagers plus babies still being carried) must be below the
    cap -- 90 in the stock game (the patcher's population modes change this number) plus 5 for each
    of the four children's collections completed (Turtle Shell, Coral, Tablet, Feather; all four
    give 25), plus 10 once Magic technology is level 3 or higher -- AND enough huts must have been
    rebuilt: a population of 10-16 needs at least 1 rebuilt hut, 17-34 needs 2, 35 or more needs all
    3 (under 10 needs none). Code: 0x45FE30; population 0x45E8F0; base 90 at 0x45FEE3; collections
    0x42DE40(0x34/0x40/0x4C/0x58), 20->25 at 0x45FE91; Magic 0x426FC0(6) >= 3 +10; huts
    0x4321F0(0..2).

  Note: Skill order on the VV3 record (measured, native/population_export): Farming, Parenting,
        Healing, Research, Building. Tech indices (label = 0x404 + index, tech screen 0x464EEB): 0
        Science, 1 Medicine, 2 Alchemy, 3 Restoration, 4 Leadership, 5 Nature, 6 Magic.

====================================================================================================
THE TREE OF LIFE  (VV4)
====================================================================================================

Rules for all island events in this game:
  * Timing: the next island event time is kept at manager+0x170E0 in game-clock seconds (clock
    0x403750). A new village sets it to 15 minutes after creation (0x41F31B: +0x384). When the time
    has come, the event is attempted only if the population (living villagers plus babies being
    carried, 0x467610) is above 0.
  * Before every attempt the scheduler draws one random living villager of any age (0x4679B0 with no
    filters); its age (+0x1B8C) must equal its age clock (+0x1C3C, the field the conception code
    copies) -- if not, nothing is rescheduled and the scheduler tries again on its next update
    (0x43FA5B-0x43FA95). Why the two can differ was not determined.
  * Delay to the next event: the first island event after the game is started (in-memory counter
    0x4D6E04, not saved) schedules the next one 30 minutes later (+0x708); every later one schedules
    the next 8 to 15 hours later ((rand(8)+8) x 3600 s). The other rand(100) rolls at
    0x43FA9B/0x43FABA/0x43FACD do not change this (0x416EB0 always returns 0).
  * When a village is loaded and an internal value manager+0x17110 is 999 or more (meaning not
    determined), the time since the last save is added to the next-event time (0x420330-0x420359).
  * Choice (selector 0x418000): every slot 1-49 whose own condition holds is collected and one is
    picked uniformly at random. No retries: if none qualifies nothing happens (the next event was
    already rescheduled).
  * Rescue rule (0x4180A5-0x4180F2): if (men outnumber women and there are at most 2 women), or (men
    do not outnumber women and there are at most 2 men) -- living villagers of all ages, 0x467650 --
    or the population including carried babies is below 3, then with a 15% chance, if the category
    roll was 60 or more (0x4180E8-0x4180F0: below 30 or below 60 skips), the choice is replaced by
    Daredevil Barrel...of Babies! (slot 25) WITHOUT checking
    its condition.
  * No event in this game is limited to once per village: the per-slot 'shown' bytes at
    0x4CC9F4+slot (written at 0x418136) are never read.
  * Ages: 20 age units = 1 displayed year. The picker 0x4679B0(minAge, maxAge, sex, allowPregnant,
    allowSick, skill, minSkill, mustBePregnant, mustBeSick, &count) counts only villagers present
    (+0x1CC4), not marked dead (+0x1CC7) and with health above 0 (+0x1C40). 'Child' = under 14 (280
    units), 'adult' = 14 or over. There is no Tribal Chief exclusion in this game.
  * Room check (used by the events that add villagers): room for new villagers, by the game's own
    room check: the population (living villagers plus babies still being carried) must be below the
    cap -- 90 in the stock game (the patcher's population modes change this number) plus 5 for each
    of the four children's collections completed (Fish Scale, Lab Equipment, Mausoleum Mural, Wind
    Flute; all four give 25) -- AND enough huts rebuilt: a population of 10-16 needs at least 1
    rebuilt hut, 17-34 needs 2, 35 or more needs all 3 (under 10 needs none).

  Note: Puzzle ids (from each puzzle's registration call to 0x4386A0 and the tip its class shows): 0
        Cutting Tools, 1 The Stream, 2 Boiling Water, 3 Soap, 4 Butterflies, 5 Frog Rescue, 6
        Cooking Pit, 7 Cloth, 8 Nursery School, 9 Mossy Rocks, 11 Fishing Nets, 12 Pruning the Tree,
        13 Honoring the Tree, 14 Purify Tree, 15 Decorating the Tree, 16 Grand Feast, 19-25
        hut/building projects (threshold 2000).

====================================================================================================
NEW BELIEVERS  (VV5)
====================================================================================================

Rules for all island events in this game:
  * Timing: the next island event time is kept at manager+0x17D3C in game-clock seconds (clock
    0x4036E0). A new village sets it to 15 minutes after creation (0x424854: +0x384). When the time
    has come, the event is attempted only if the believer population (living believers plus babies
    they carry, 0x4713F0) is above 0 AND an internal global 0x51D5A4 equals -1 (meaning not
    determined; the stock code only ever writes -1 to it, at 0x44356F in a message handler, and
    0x446131 makes the same test elsewhere).
  * Before every attempt the scheduler draws one random living believer of any age (picker with no
    other filters); its age (+0x1B8C) must equal its age clock (+0x1C3C) -- if not, nothing is
    rescheduled and the scheduler tries again on its next update (0x442715-0x442754). Why the two
    can differ was not determined.
  * Delay to the next event: the first island event after the game is started (in-memory counter
    0x51D37C) schedules the next one 30 minutes later (+0x708); every later one schedules the next 8
    to 15 hours later ((rand(8)+8) x 3600 s). The other rand(100) rolls at
    0x44275A/0x442771/0x442784 only pick between code paths that all end the same way (0x417650
    always returns 0).
  * When a village is loaded and an internal value manager+0x17D7C is 999 or more (meaning not
    determined), the time since the last save is added to the next-event time (0x425E36-0x425E54).
  * Choice (selector 0x418870): every slot 1-55 whose own condition holds is collected and one is
    picked uniformly at random. No retries: if none qualifies nothing happens.
  * Rescue rule (0x418913-0x418956): if (men outnumber women and there are at most 2 women) or (men
    do not outnumber women and there are at most 2 men) -- 0x472B80 -- or the believer population is
    below 3, then with a 15% chance, if the category roll was 60 or more (0x41894C-0x418954: below
    30 or below 60 skips), the choice is replaced by Chutes Without Ladders (slot 30) WITHOUT checking
    its condition.
  * No event in this game is limited to once per village: the per-slot 'shown' bytes at
    0x4DC814+slot (written at 0x41899A) are never read.
  * Ages: 20 age units = 1 displayed year; 'child' = under 14 (280), 'adult' = 14 or over. The
    picker 0x471870 counts only villagers present (+0x1CD4), with an internal flag +0x1CE1 clear
    (meaning not determined) and health above 0. Unless an event asks for Heathens, Heathens
    (+0x1CEC set) are skipped. Every event's picker also skips villagers whose status +0x1CFC is
    12-17 (13 is the Retired Chief and 17 the Heathen Mommy; 12 is the purple-mask rank; 14-16 not
    determined).
  * Room check (used by the events that add villagers): room for new villagers, by the game's own
    room check: the believer population (living believers plus babies they are carrying -- Heathens
    are not counted) must be below the cap -- 90 in the stock game (the patcher's population modes
    change this number) plus 5 for each of the two children's collections completed (Relics and Lab
    Equipment; both give 15) -- AND enough huts rebuilt: a population of 10-16 needs at least 1
    rebuilt hut, 17-34 needs 2, 35 or more needs all 3 (under 10 needs none).

  Note: Tech indices (labels 0x44D+index): 0 Science, 1 Medicine, 2 Learning, 3 Construction, 4 Food
        Mastery, 5 Spirituality; levels read with 0x423600 on 0x51D5CC.
  Note: Puzzle ids (from each puzzle's registration call to 0x43ABB0 and the tip its class shows)
        used here: 4 The Knowing Totem, 5 The Hydroponic Farm, 13 The Heathen Scientist, 19-21 huts.

====================================================================================================
NOT FULLY RESOLVED
====================================================================================================
  * The Secret City "The Mushroom Celebration" and The Tree of Life "The Festival of the Banyan": the
    500 counter is exact, but which delivered item ids count as mushrooms (as opposed to other
    non-collection items) was not established.
  * Internal fields whose meaning was not determined (their required value is stated exactly): the
    per-attempt "age equals +0x34C / +0x534 / +0xE74 / +0x1C3C" check in all five games; VV1/VV2/
    VV3/VV4/VV5 load-time value (999 or more) that adds offline time; New Believers global 0x51D5A4
    (must be -1); New Believers picker flag +0x1CE1 (must be clear) and statuses 14-16 of +0x1CFC;
    The Tree of Life stream flag 0x4D8CF0+4.
  * Technology names for A New Home (+0xA2BC Spirituality, +0xA2D4 Medicine, +0xA2E4 Farming) and
    The Lost Children (+0x2EA74 Culture, +0x2EA94 Exploration) come from pairing the Technologies
    screen's row order with its label order; Medicine (VV1) and Engineering (VV2) are independently
    corroborated, the others are not.
  * The Secret City "Day of Honor" counts a 50-entry table at 0x5973F0 (not the Roster of the Dead,
    which is counted by 0x454BC0); that its entries are graves is inferred from the event and from
    an idle-task chooser that uses the same count (0x45A151), not proven.

====================================================================================================
FOUND IN PASSING (recorded, not changed)
====================================================================================================
  * The current "requires" texts in scripts/story_island_events.py are wrong in several places, e.g.
    VV1 The Trapped Whale / The Visitor ("happened fewer than three times" -- they compare a
    technology level with 3); VV2 The Ancient Gold Coin / The Spyglass ("fashion caught on" / "kept
    already" -- they compare a technology level with 2); VV2 The Epidemic, Rats!, The Foul Passing,
    Where Are The Infants? ("later technologies" -- the check is all 16 puzzles solved); VV3 Vanity
    and the Bee / The Noisy Bird ("a villager" -- it must be a woman 18-49 not pregnant); VV3 The Low
    Tide ("a child" -- any 8 villagers); VV4 The Pretty Shell (the code counts villagers 14 and over,
    not children); VV5 Spa / Cracked Mask / Spying / Missing Kids / You're Doing It Wrong also need a
    Heathen child.
  * docs/village-statistics-export-research.md and tests/test_vv3_chief_puzzle_is_a_one_shot_latch.py
    call VV3 puzzle id 1 the Tribal Chief robe puzzle. The evidence here points elsewhere: puzzle 1's
    handler object (0x4B0D88[1]) is the honey resource 0x5945D0 (The Bee Hive), and the chief-making
    routine 0x45FBC0 is called only at 0x431FEA, beside the "The First Chief" tip (0x2BF) and
    AdvancePuzzle(0) at 0x432031 -- so the chief is puzzle 0. Not re-verified live.
  * docs/mask-identity-safeguard.md lists VV3 skills at +0xEB0 Building / +0xEB4 Research /
    +0xEB8 Healing; native/population_export (measured live) gives Farming, Parenting, Healing,
    Research, Building. This file uses the measured order.
  * The stock rescue overrides in The Secret City, The Tree of Life and New Believers replace the
    chosen event without asking the replacement's own condition (so, for example, Another One of
    Those Barrels can be chosen in a village with no room; in the stock game its first baby is
    added regardless and later ones only while there is room -- docs/island-event-population-
    research.md).
