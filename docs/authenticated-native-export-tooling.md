# Authenticated VV3-VV5 native evidence export tooling

This tooling is read-only. It does not start a game, IDA, or Ghidra; inspect
saves; patch an executable; or accept files outside a declared copied workspace
root. IDA/Ghidra templates may be run only in a later explicitly authorized
session.

## Preflight and dry-run

Copy a complete stock game folder beneath a self-contained workspace input
directory. Do not point the tool at an installed game or user-data directory.

```text
python tools/native_evidence_export.py inventory --workspace-root inputs --game-folder inputs/vv3-stock-copy --game vv3
python tools/native_evidence_export.py plan --workspace-root inputs --game-folder inputs/vv3-stock-copy --game vv3
```

The preflight rejects an empty folder, a folder outside the declared root,
links/reparse points, non-regular files, identity changes while hashing, and an
incorrect executable name, size, or SHA-256. The canonical inventory is sorted
by case-folded relative path and binds every file's path, size, and raw hash.
It never follows a linked artifact. The plan has `dry_run:true` and `writes:[]`.

## Disassembler export

`data/native_evidence_queries.json` requires ten query families: selected
index/world resolver; funds getter and setter; age setter, companion fields and
Oldest; preference setter/readback/queue; confirmation ABI; postverify/fault
boundary; fullscreen leave/enter/owner; stored indices; and save loader/
serializer. The IDA and Ghidra templates refuse an incomplete resolved-EA map.
They extract function bounds, EA, file offset, bytes, instructions, callers and
xrefs from the loaded database. Any still-unresolved register or cleanup marker
causes final validation to fail.

After an authorized exporter run places its JSON inside the same workspace:

```text
python tools/native_evidence_export.py validate --workspace-root inputs --game-folder inputs/vv3-stock-copy --game vv3 --export inputs/vv3-export.json
```

The validator requires all ten rows in canonical order, exact source binding,
machine generator identity, `synthetic:false`, `manual:false`, nonempty
instruction/register/ABI evidence, source-byte equality at every file offset,
and a canonical artifact hash. Partial, duplicate, reordered, stale, pasted,
manual, and synthetic data fail closed.

The same commands support `vv4` and `vv5`. Nothing generated by these tools is
publication or runtime/player proof by itself; independent review and the
existing evidence gates remain required.
