EVERY ISLAND EVENT CAN HAPPEN - REQUIREMENTS TABLE (v1.35.97)
=============================================================

Research only. Nothing is implemented. Planned patch: "Every Island Event Can Happen" (working name),
its own patch, all 5 games, ON in Owner's Defaults.

The three classes (owner's rules)
  SAFETY       Kept, unless the separate "No Safeguards" patch is also on. Villager, population, room,
               puzzle-progress requirements and similar.
  MAKES SENSE  Always kept. Something the event's own text uses (a building, item, villager, puzzle
               state), a rescue event's tie to the trouble it rescues from, and the opening events.
  DROPPED      Removed by this patch: technology levels / tech points, time of day, food or stock
               amounts that are not the event's subject, waiting periods / cooldowns, once-only flags.
  A few SAFETY rows are marked [HARD]: they stop a crash, a corrupt save or a broken result, so they
  stay even with both patches on.

What the stock code does NOT have (so there is nothing to drop)
  - No island event in any of the 5 games checks the time of day.
  - No island event has its own cooldown or a once-per-village flag. VV3, VV4 and VV5 write a "shown"
    byte per event (VV3 0x419C22, VV4 0x418136, VV5 0x41899A) but never read it.
  - The only waiting period is the shared timer between ANY two island events (VV1 12-23 h, VV2 10-19 h,
    VV3-VV5 8-15 h). It decides WHEN an event comes, not WHICH; this table leaves it alone (see Q1).
  So in practice DROPPED = technology gates (all 5 games) plus nothing else.

Sources and checking
  Requirements: docs/reports/island-event-conditions.txt and docs/no-safeguards-island-events.md
  (feat/97-round6). Every condition address below was disassembled again in the stock exes
  (the five stock executables, research/stock-executables) for this table and matched the compare / call it is
  quoted with. Static analysis only, not yet seen in a running game.
  Extra checks made for this table (the tech gates that would be dropped):
    - VV1 Trapped Whale / Visitor results raise the level only while it is below 3 (0x4193F4, 0x41981B).
    - VV2 Gold Coin result raises Culture only while it is below 2 (0x420524).
    - VV2 Spyglass result SETS Exploration to 2 (0x421E7D) - it would LOWER a level-3 village. See Q3.
    - VV3 tech raise 0x426FD0 and VV5 tech raise 0x423610 stop at level 3. VV4's 0x41E1D0 stops at 3.
  So dropping the tech gates cannot push a level past 3 (except the VV2 Spyglass row, kept [HARD]).

Format: each event, then each requirement: [CLASS] requirement - reason. (address)
"Any villager" = a living villager of any age, the event's subject.
