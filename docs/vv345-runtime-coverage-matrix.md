# VV3-VV5 runtime coverage matrix

This disabled matrix inventories the 16 catalog-visible VV3/VV4/VV5 records at C348 `e43464eb21667aba619d63272a808b0540ccf015` and both Expanded-256 modes for each game. It does not launch a game, inspect a save, emit native bytes, package artifacts, or authorize publication.

Every visible patch requires separate windowed and fullscreen receipts for success, no-op, failure, uninstall, composition, and crash/hang monitoring. Receipts must bind the exact complete-folder inventory, source and output hashes, selected modes and features, before/after state, dialog text, charge result, process exit, hang timeout, and uninstall restoration.

Each Expanded-256 mode additionally requires stock import, a completed full save, reload, offline catch-up, failed-load nonmutation, three-generation rotation, and physical/logical boundary receipts for records 149, 150, 254 and 255. Composition receipts must cover Origins with each currently visible dependent row and must demonstrate that unavailable/hidden actions remain absent.

Missing inputs are explicit: complete self-contained VV3/VV4/VV5 folders, exact backed-up stock saves, expanded saves populated through all four boundary records, deliberately invalid saves, and three save generations per game. The repository contains static candidates and preparation harnesses, not runtime or player proof. The VV3 historical load-hang and withdrawn Running crash remain unresolved observations, not passing receipts.

Publication, native, runtime and player flags remain false. This matrix is additive and may be integrated after C348 without changing catalog behavior.
