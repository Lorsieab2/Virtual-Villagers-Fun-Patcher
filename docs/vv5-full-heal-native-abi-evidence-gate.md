# VV5 Full Heal native ABI evidence gate

This additive record describes the evidence required for a future real VV5
`Full Heal / Cure All` implementation. It does not upgrade the existing
callback model: that model remains reference-only and cannot qualify as native
ABI, lifecycle, readback, rollback, or player evidence.

The checked-in gate is STOP, disabled, catalog-hidden, publication-false, and
native-output-false. Every unknown native field remains null. Full Heal owns no
range, patch, hook, or cave; the UI remains exactly four actions. No package,
launch, or save access is part of this artifact.

The confirmation and result evidence must retain natural singular/plural-safe
wording: `Full Heal / Cure All`, `X sick villagers were cured`, and `Y
partial-health villagers were restored to exactly 100`. A sick partial-health
villager contributes once to each count.

Even a schema-complete record remains publication-false. Native implementation,
enablement, packaging, and player validation require a separate authorized and
independently reviewed scope.
